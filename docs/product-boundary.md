# LinkLoom 产品边界

LinkLoom 是单维护者后台 + 公开只读前端的自托管资讯生产应用。

## 做什么

- 一个管理员维护采集源、AI 工作流、发布渠道和系统设置。
- 读者无需账号，访问公开 Web、RSS、Feed timeline、picks 和 report-json。
- 默认单节点运行，业务数据保存在 PostgreSQL，资源文件在 `data/` 目录。
- 工程重点是稳定部署、备份恢复、日志诊断、安全默认值和回归测试。

## 不做什么

- 不做读者账号、评论、订阅付费和用户画像。
- 不做多租户、团队协作、复杂 RBAC。
- 不默认支持多个后端写实例同时运行。
- 不把 Redis、对象存储、Kubernetes 作为当前默认部署要求（PostgreSQL 为必需依赖）。

## 运行边界

- 只对外暴露 backend `PORT`，不要直接暴露 Next `NEXT_PORT`。
- 只运行一个后端写实例，否则 node-cron 调度任务可能重复执行。
- `data/` 是核心资产，升级、迁移、清理前先备份。
